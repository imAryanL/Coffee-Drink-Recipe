# ☕ On My Grind - Coffee Drink Guessing Game

An engaging, Wordle-inspired coffee game where players test their barista skills by guessing the correct ingredients for random Starbucks drinks. Built with React and featuring a coffee-themed interface, this interactive web application challenges players to master the art of drink customization through strategic guessing and instant feedback.

## ✨ Features

### **Interactive Gameplay**
- **Random Drink Generation** - New Starbucks drink orders for endless replayability
- **Four-Component Guessing** - Temperature, milk type, syrup flavor, and blending options
- **Instant Visual Feedback** - Color-coded system showing correct and incorrect answers
- **Dynamic Input System** - Click options or type custom responses with validation

### 🥛 **Drink Customization System**
- **Temperature Options** - Hot, cold, and lukewarm selections
- **Milk Varieties** - Cow, oat, and other milk alternatives
- **Syrup Flavors** - Multiple flavor options for drink customization
- **Blending Choices** - Blended or non-blended drink options

### 🎨 **User Experience**
- **Coffee-Themed Design** - Engaging, barista-inspired interface
- **Responsive Layout** - Works seamlessly on desktop and mobile devices
- **Input Validation** - Ensures proper drink component selection
- **Game State Management** - Smooth transitions between drinks and rounds

## 🚀 Technologies Used

- **React** - Component-based architecture with hooks and state management
- **useState Hook** - Dynamic state management for game progression
- **CSS3** - Custom styling with coffee-themed design elements
- **JavaScript (ES6+)** - Modern JavaScript features and game logic
- **JSON Data Management** - Structured drink data and game state
- **Form Handling** - User input validation and submission processing

## How to Play

1. **Study the Drink** - Examine the random Starbucks drink order
2. **Guess Ingredients** - Select or type your guesses for each component
3. **Check Your Answer** - Submit your guess to see how you did
4. **Learn from Feedback** - Use color-coded indicators to improve
5. **Try Again** - Get a new drink and test your skills further

## 🛠️ How to Run

### **Using Terminal (Recommended)**

1. **Clone the repository**:
   ```bash
   git clone https://github.com/imAryanL/on-my-grind.git
   cd on-my-grind
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Start the development server**:
   ```bash
   npm run dev
   ```

4. **Open your browser** and navigate to `http://localhost:5173`

### **Alternative Commands**

If `npm run dev` doesn't work, try:
```bash
npm start
```

## Architecture

### **Component Structure**
- **Game Controller** - Main game logic and state management
- **Drink Display** - Shows current drink order and game status
- **Input System** - Handles user selections and typed responses
- **Feedback Display** - Visual indicators for correct/incorrect answers
- **Game Controls** - New drink generation and answer checking

### **State Management**
- **Game State** - Current drink, user guesses, and game progress
- **User Input** - Dynamic form handling with validation
- **Feedback System** - Real-time response to user actions
- **Drink Generation** - Random selection from drink database

### **User Interface**
- **Coffee Theme** - Engaging, barista-inspired visual design
- **Responsive Layout** - Mobile-first approach with CSS Grid/Flexbox
- **Interactive Elements** - Clickable options and smooth transitions
- **Visual Feedback** - Color-coded system for immediate response
